# UI specification

Numeris käyttää Material 3:a, edge-to-edge-sisältöä ja tummaa matte-taustaa. Dynamic Color on pois käytöstä.

- Background `#151419`
- Card `#F017181D`
- Control `#F0222526`
- Primary text `#FBFBFB`
- Secondary text `#DAD4CC`
- Accent `#F56E0F`
- Copper `#E09145`
- Warm Platinum `#FCD9B8`

Spacing perustuu 4 dp:n asteikkoon, kortin oletussäde on 12 dp ja kosketusalue vähintään 48 x 48 dp. Kompakti ikkuna käyttää bottom navigationia; medium/expanded käyttää navigation railia. Kaavioilla on aina saavutettava tekstiyhteenveto. Ei bluria, glassmorphismia, gradienttiorbeja, jatkuvaa pulssia tai koristeellista loop-animaatiota.
